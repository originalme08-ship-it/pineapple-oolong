# Проект

Тестовое задание на HTML, CSS и JavaScript.

## Запуск

1. Скачайте проект.
2. Откройте файл `index.html` в браузере.

Дополнительная установка зависимостей не требуется.

### Структура проекта

```text
pineapple-oolong/
├── index.html
├── assets
    ├── tea-1.jpg
    ├── tea-2.jpg
    ├── tea-3.jpg
├── js
    ├── main.js
├── styles
    ├── style.css
    ├── style.css.map
    ├── style.scss
```

### Запуск через браузер

Можно просто открыть `index.html` двойным кликом или перетащить его в окно браузера.

Также можно открыть файл через адрес:

```text
file:///pineapple-oolong/index.html
```
